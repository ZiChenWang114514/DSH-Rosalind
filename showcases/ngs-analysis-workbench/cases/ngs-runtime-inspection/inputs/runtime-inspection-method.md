# Runtime inspection method

The Workbench runtime snapshot is the primary source for the registered local controller. A second, narrowly scoped OpenSSH probe records the visible runtime on the authorized SSH compute target without retaining aliases or connection identities.

The word `missing` means that a command was not found on the inspected noninteractive `PATH`. It does not claim that no copy exists elsewhere. Docker client availability and Docker server reachability are separate observations.

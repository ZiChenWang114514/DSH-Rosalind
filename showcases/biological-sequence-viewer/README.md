# Biological Sequence & Alignment Viewer

Version tracked by this framework: `0.1.43`.

## Registered showcases

1. `sequence-lambda-annotation` — annotated lambda genome and cI translation.
2. `sequence-ras-alignment` — KRAS/NRAS/HRAS alignment, conservation, distances, and exploratory tree.
3. `sequence-fastq-qc` — bounded public-read quality exploration.

Store source accession and version information, the exact opened artifact, viewer queries, exported results, and at least one representative preview. Tree and QC results must retain their method descriptions.

# Public acquisition

- Open structure: RCSB PDB 4AKE, https://files.rcsb.org/download/4AKE.pdb
- AP5-bound structure: RCSB PDB 1AKE, https://files.rcsb.org/download/1AKE.pdb
- 4AKE revision recorded by the repository source example: major 1, minor 3, 2024-02-28
- 1AKE revision recorded by the repository source example: major 1, minor 4, 2024-12-25
- Retained files: `inputs/4AKE.pdb` and `inputs/1AKE.pdb`

The coordinate files were reused byte-for-byte from the repository's verified `structure-adenylate-kinase` showcase. `build_case.py` requires their recorded SHA-256 values before computing any metric.

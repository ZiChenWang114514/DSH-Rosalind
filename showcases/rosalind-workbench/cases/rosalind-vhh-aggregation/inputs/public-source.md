# Public sequence acquisition

RCSB FASTA downloads were retrieved on 2026-08-30.

- PDB 5M2W, llama nanobody nb8 against TssK: https://www.rcsb.org/structure/5M2W
- PDB 6WAQ, llama SARS VHH-72: https://www.rcsb.org/structure/6WAQ
- PDB 4KRL, llama EGFR VHH 7D12: https://www.rcsb.org/structure/4KRL

`vhh-polymer-sequences.fasta` preserves each RCSB polymer sequence exactly. The analysis uses the portion ending at the conserved terminal `VTVSS` motif, thereby excluding C-terminal affinity tags or cloning residues while leaving the source sequences inspectable. No structure model, solvent-accessibility calculation, or aggregation experiment was run.

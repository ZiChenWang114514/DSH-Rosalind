# Public acquisition: PETase structure

- Source: https://www.rcsb.org/structure/5XJH
- Checked: 2026-08-30
- Record: PDB 5XJH, an X-ray crystal structure of PETase from *Ideonella sakaiensis*.
- Reported resolution: 1.54 Å.
- Public record summary: a 300-residue, mutation-free PETase chain; the linked primary report describes a Ser–His–Asp catalytic triad.
- Teaching use: establish the reference structure and catalytic-region context for reviewing already reported substitutions.
- Limitation: this case retains no substitution list or coordinate-distance calculation, so it does not place mutations relative to the catalytic region.

# Public acquisition: GFP chromophore structure

- Source: https://www.rcsb.org/structure/1EMA
- Checked: 2026-08-30
- Record: PDB 1EMA, a 1.90 Å X-ray structure of an *Aequorea victoria* GFP variant.
- Public record summary: the linked primary report describes an 11-stranded beta barrel, a coaxial central helix, chromophore formation from residues 65–67, and Thr203 adjacent to the chromophore.
- Teaching use: establish public structural context for a later, explicitly parameterized pocket query.
- Limitation: this case retains no coordinate-derived contact list or distance cutoff, so it does not define the complete chromophore pocket.

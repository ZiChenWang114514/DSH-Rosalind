# Paired-structure RMSD

Using the retained RCSB 4AKE and 1AKE coordinate snapshots, compare author chain A by pairing Cα atoms with the same author residue number, insertion code, and residue name. Apply an unweighted Kabsch fit, report the global RMSD and the CORE, NMP, and LID domain diagnostics, and distinguish local domain similarity from displacement after the global fit.

Inspect `outputs/rosalind-open-observation.json` as a separate launcher-availability observation. It records only that Rosalind Workbench was ready; do not describe it as a Rosalind scientific calculation.

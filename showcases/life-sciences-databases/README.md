# Life Sciences Databases

Version tracked by this framework: `0.1.5`.

The plugin contains 44 source-specific skills. The initial gallery uses three integrated demonstrations:

1. `databases-il6r-asthma` — genetics, expression, and target evidence.
2. `databases-variant-interpretation` — ClinVar, gnomAD, Ensembl, and cohort evidence.
3. `databases-egfr-landscape` — structures, pathways, ligands, and pharmacology.

Each source response must retain its database identifier, query date, canonical record link, direct observations, and any unresolved mismatch between sources. Individual database demonstrations can be added later without changing the catalogue format.
